# Nom du projet : Projet "Evenement"

## Présentation 

Mon application est une plateforme simple permettant d’afficher et de gérer des évènements scolaires. Elle centralise toutes les informations importantes comme la date, le lieu, la description ou les consignes liées à un évènement.


## Objectif 

Quel problème l'application cherche-t-elle à résoudre ?

L’objectif est d’éviter la dispersion des informations sur plusieurs outils (Teams, Instagram, messages privés) et de proposer un espace unique où les évènements sont consultables facilement.

## Fonctionnalités principales 
- Consulter un évènement 
- Ajouter/Modifier/Supprimer un évènement


## Technologies envisagées 
- Frontend : HTML/CSS et JavaScript
- Backend : SpringBoot
- Base de données : PostgresSQL
