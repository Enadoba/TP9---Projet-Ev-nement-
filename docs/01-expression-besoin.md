## Fonctionnnalités

Etudiant :

- L'étudiant doit pouvoir consulter les évènements.

Professeur :

- Le professeur doit pouvoir consulter les évènements.
- Le professeur doit pouvoir ajouter les évènements.
- Le professeur doit pouvoir modifier les évènements.
- Le professeur doit pouvoir enregistrer qui participe à l'évènement

Bonus :

- Rajouter les différents rôle (Etudiant, professeur)
- L'étudiant doit pouvoir modifier les évènements si l'étudiant est l'auteur de cet évènement.
- L'étudiant doit pouvoir ajouter des évènements.
- L'étudiant doit pouvoir s'enregistrer qu'il pourra participer ou non à l'évènement
